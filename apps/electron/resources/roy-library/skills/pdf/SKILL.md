# PDF 处理

## 常见任务
| 要做的事 | 推荐做法 |
| --- | --- |
| 提取文字 | pypdf 或 pdfplumber；扫描件先说明需要 OCR |
| 提取表格 | pdfplumber 的表格提取，结果转成 CSV 给用户核对 |
| 合并 / 拆分 / 旋转 | pypdf |
| 加水印、页码 | 先生成一页透明水印，再逐页叠加 |
| 填表单 | 先列出所有表单字段名，再按字段填写 |

## 注意
- 原文件不动，输出写到新文件。
- 扫描件、加密文件要先告诉用户限制，不要假装已经读出内容。
- 交付时说明页数、输出路径，以及有没有读不出来的页。
