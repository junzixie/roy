# 小红书创作

## 流程
1. **定读者和场景**：谁会搜到这篇、在什么情况下搜。
2. **标题给 5 个备选**：20 字以内，包含具体收益或数字，避免夸大和绝对化用语（如「最」「第一」「100%」）。
3. **正文结构**：开头两行说清楚痛点或结果 → 分点讲方法或经历 → 结尾给一个可执行的建议或提问引导互动。
4. **语气**：像朋友分享，第一人称，段落短，可以适量用表情符号分隔。
5. **标签**：5–8 个，从大类到细分都有。

## 不要做
- 编造亲身经历、数据和效果。
- 医疗、金融类内容给出确定性承诺。
