# PPT 演示

## 先定结构
1. 问清楚：给谁看、讲多久、要对方记住哪一句话。
2. 先出一页一句话的大纲给用户确认，再做页面。一页只讲一个观点。

## 页面要求
- 标题写结论，不写「背景介绍」这类空标题。
- 每页文字不超过 6 行；细节放备注栏。
- 数字能画图就画图；同一份演示里配色和字体统一。

## 怎么做
- 优先用 Roy 自带的 `officecli`；没有时用 Python 的 python-pptx。
- 改现有文件时沿用它的母版和版式，不要自己另起一套样式。

## 交付前检查
- 逐页导出缩略图或重新读取，确认没有文字溢出、图片缺失。
