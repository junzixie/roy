# 系统排错

1. **复现**：先拿到稳定复现的步骤或命令。复现不了就先补日志，不要猜着改。
2. **缩小范围**：二分法定位——是哪次改动、哪个模块、哪个输入引起的。
3. **找根因**：问「为什么」直到答案是代码或配置里的具体一行，而不是「偶尔会这样」。
4. **最小修复**：只改根因，不顺手重构。
5. **验证**：用第 1 步的复现方式确认问题消失，再跑相关测试确认没有引入新问题。
6. **汇报**：现象、根因、改了什么、怎么验证的。
