# 深度调研

1. **拆问题**：把用户的问题拆成 3–6 个子问题，先给用户看一眼。
2. **搜索**：每个子问题至少看 2 个独立来源；优先官方文档、原始数据、一手报道。
3. **核对**：同一个事实来源说法不一致时，写出分歧，不要自己挑一个当结论。
4. **记录出处**：每条关键信息记下链接和发布日期，过期信息要注明。
5. **成文**：开头给结论和可信程度，然后按子问题展开，最后列来源清单。

没有搜索工具时，明确说明只能凭已有知识回答，并标出哪些需要用户自行核实。
