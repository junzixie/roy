# 做 MCP

1. 先列出 AI 需要做的 3–5 件事，每件对应一个工具；工具名用动词开头，描述写清楚什么时候用。
2. 参数尽量少而明确，用 JSON Schema 写清楚类型和必填项。
3. 返回结果给 AI 读：简洁、有结构，出错时说明原因和下一步怎么办。
4. 用官方 SDK（TypeScript 或 Python）实现，先用 stdio 方式本地跑通。
5. 在 Roy 的「MCP」里添加这个服务，实际调用一次每个工具，确认能用。
6. 涉及密钥的放环境变量，不写进代码。
