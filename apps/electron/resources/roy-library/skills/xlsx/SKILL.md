# Excel 表格

## 原则
- **能用公式就别写死数字**：合计、占比、增长率都写成公式，用户改源数据时结果会跟着变。
- 一张表只放一类数据，第一行是表头，不合并单元格（合并会让筛选和透视失效）。
- 金额、百分比、日期设好单元格格式，不要用文本存数字。

## 怎么做
1. 优先用 Roy 自带的 `officecli`；没有时用 Python 的 openpyxl（要保留公式时别用 pandas 直接覆盖写）。
2. 读现有表时先列出所有工作表和表头，再决定改哪里。
3. 需要图表时，图表引用单元格区域，不要贴图片。

## 交付前检查
- 用脚本重新读一遍，确认公式没有 #REF!、#DIV/0! 之类的错误。
- 说明哪些单元格是公式、哪些是你填的原始数据。
