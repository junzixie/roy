# Word 文档

## 先判断要做什么
- **新写一份**：先和用户确认读者、用途、篇幅和大致目录，再动笔。
- **改现有文件**：先完整读一遍原文，弄清结构和格式，只改用户要求的部分。
- **只读内容**：提取文字和表格即可，不要顺手改文件。

## 怎么做
1. 优先用 Roy 自带的 `officecli`（先运行 `officecli --help` 看可用命令）；没有时用 Python 的 python-docx。
2. 标题用真正的标题样式，不要用加粗大字冒充，目录才能自动生成。
3. 表格要有表头；数字列右对齐、单位写在表头里。
4. 改现有文件前先复制一份备份，文件名加 `.bak`。

## 交付前检查
- 重新打开生成的文件，确认能读、段落和表格都在。
- 告诉用户文件的完整路径，以及哪些地方是你推测补写的。
