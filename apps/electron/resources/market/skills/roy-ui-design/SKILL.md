# 界面设计

## 先定三件事，再写代码

1. **主题和读者**：这个界面给谁用、只做一件什么事。从主题自己的世界取材（行业术语、真实单位、真实数据），不用占位文字。
2. **风格**：用户指定了就照做；没指定就从下面挑一种最贴合主题的，说一句为什么选它。
3. **设计变量**：在样式最顶部写成 CSS 变量：4–6 个颜色、2 种字体（标题 / 正文，可加一个数字或代码字体）、圆角和间距刻度。后面所有样式只引用变量。

## 风格库

| 风格 | 适合 | 要点 |
|---|---|---|
| 极简留白 | 工具、设置页、个人作品 | 大量留白，一种强调色，细分隔线代替卡片，字重拉开层级 |
| 稳重可信 | 金融、企业、后台 | 深蓝或墨绿主色，表格数字等宽对齐，状态用色块和图标双重表达 |
| 杂志排版 | 文章、报告、品牌故事 | 衬线标题配无衬线正文，正文每行约 35 个汉字，图片满版，少用按钮 |
| 网格秩序 | 数据页、作品集、产品列表 | 严格 12 栏网格，统一基线，标题左对齐，不居中堆叠 |
| 活泼动效 | 消费品、活动页、儿童教育 | 饱和撞色，大圆角，进场只做一次编排好的动画，悬停有反馈 |
| 终端暗色 | 开发者工具、命令行产品 | 近黑底，等宽字体做强调，代码块是主角，强调色只用一种荧光色 |
| 粗野主义 | 个性品牌、独立项目 | 粗黑边框、硬阴影、不对齐的刻意张力，颜色少而纯 |

## 每次都要做到

- 同时设计浅色和深色：变量在 `:root` 定义一遍，深色再覆盖一遍；不要在组件里写只适合一种主题的颜色。
- 手机宽度（约 400px）可用：左右至少 16px 边距，横向不滚动，多栏在窄屏变单栏。
- 间距用 flex / grid 的 `gap`，少用零散的 margin。
- 键盘焦点可见，图片有替代文字，尊重系统的「减少动态效果」。
- 动效有目的：一处精心编排胜过处处在动。

## 避免这些一眼就是 AI 做的样子

- 紫到蓝的渐变大头图、所有东西都居中、每个块都是同样的圆角加阴影卡片。
- 用 emoji 当小标题图标，01 / 02 / 03 编号但内容并不是步骤。
- 默认字体一把梭，没有字号刻度。

## 交付前自查

打开页面实际看一眼（截图或预览）：文字有没有被截断、元素有没有重叠、深浅色是否都可读、窄屏是否正常。说明里只写做了什么、哪些没验证，不夸效果。
