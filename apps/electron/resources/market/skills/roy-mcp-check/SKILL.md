# MCP 连接检查

1. 区分市场条目、工作区启用配置、连接成功、工具注册和执行成功五层。
2. 优先查看当前可见的 mcp__ 工具与 mcp_connection_status；未连接不能伪造工具调用。
3. 文件系统服务优先调用 list_allowed_directories 这一只读工具；需要验证推理服务时调用其实际公开工具。
4. 记忆服务只有用户明确需要保存或查询项目知识且启用时才使用，不写入凭据和无关个人信息。
5. 连接失败输出服务名与阶段，不输出环境变量、令牌或请求头。不反复重试或自动安装未知服务。
6. 更改连接配置遵循已有权限，完成后区分协议探针、桥接测试和真实模型会话验收。
