# 正式验收清单

> 与 `docs/交付就绪评估.md` 配套。  
> 自动化前置：在仓库根执行 `bun scripts/smoke-formal-check.mjs`（须通过）。  
> 下列手工项签字后，可将判定从「可试用」升为「可正式」。

## A. 一键构建（Windows）

在 `C:\Users\Administrator\Desktop\Roy`：

```bat
bun install
bun run build:cli
bun run typecheck
bun scripts/smoke-formal-check.mjs
bun run dist:win
```

说明：
- `build:cli` 产出 `apps/electron/resources/bin/roy.exe`
- `dist:win` 产出安装包（耗时长；需本机已配 electron-builder 依赖）
- 若只验证开发态：可跳过 `dist:win`，但**不可**因此称安装版正式就绪

## C. 手工验收（必过）

1. [ ] 设置 → 模型渠道：启用模型，Agent 正常对话  
2. [ ] 产物打开：写出文件后默认「打开工作台」  
3. [ ] 设置 → 命令行工具：打开 PATH → **新开**终端 `roy help`  
4. [ ] AI 助理：侧栏进入，下方为完整 Agent 界面；快捷条「开一个叫验收演示的项目」能建项并进入  
5. [ ] Roy **退出**后执行 `roy ask "ping"`：应提示写入 inbox 并尝试启动；再开 Roy 后任务被消化或可再 ask  
6. [ ] 界面无 `proma.cool` / `proma-ai/Proma` 用户可见链接（关于/更新日志/渠道下载/Git 署名）  
7. [ ] 助理生成中可停止；失败有明确错误（无假成功）
