# 使用阿里云域名 agares.online 配置手机遥控公网访问

## 📋 准备工作

你已经完成：
- ✅ 在阿里云购买了域名 agares.online

还需要：
- □ 将域名转到 Cloudflare（免费且简单）
- 或者有一台公网服务器

---

## 🚀 方案 A：Cloudflare Tunnel（推荐）

### 第一步：在 Cloudflare 添加站点

1. **打开浏览器访问：** https://dash.cloudflare.com
2. **登录你的 Cloudflare 账号**
3. **点击 "Add a site" 或 "添加站点"**
4. **输入域名：** `agares.online`
5. **选择 Free 计划**
6. **点击 "Continue" 或 "继续"**

### 第二步：获取 Cloudflare NS 服务器

Cloudflare 会显示两个 NS 地址，类似：
```
abel.ns.cloudflare.com
dana.ns.cloudflare.com
```

**记下这两个地址！**

### 第三步：在阿里云修改 DNS 服务器

1. **打开阿里云域名控制台**
2. **找到 agares.online**
3. **点击 "管理" 或域名右侧的操作按钮**
4. **找到 "DNS 修改" 或 "修改 DNS 服务器"**
5. **将 DNS 服务器改为 Cloudflare 提供的两个 NS 地址**
6. **保存**

**注意：** DNS 生效需要几分钟到几小时

### 第四步：等待 Cloudflare 验证

回到 Cloudflare 页面，等待域名验证完成。通常几分钟后刷新页面会显示"Active"（已激活）。

### 第五步：运行配置脚本

**打开管理员 PowerShell：**

```powershell
# 进入项目目录
cd E:\AIproject\02-roy-harness

# 运行配置脚本
.\scripts\setup-cloudflare-tunnel.ps1
```

脚本会自动：
- 安装 cloudflared
- 创建隧道
- 配置 agares.online 的 DNS 路由
- 生成配置文件

### 第六步：启动隧道

```powershell
cloudflared tunnel run roy-mobile-remote
```

保持窗口运行，或者设置为服务：

```powershell
.\scripts\install-tunnel-service.ps1
```

### 第七步：在 Roy 中配置

1. 打开 Roy → 设置 → 手机遥控
2. 开启"允许手机遥控"
3. 公网地址填入：`agares.online`
4. 点击"保存"
5. 选择"公网"模式
6. 显示固定二维码
7. 手机扫码测试

## 🔧 方案 B：使用阿里云服务器

### 前提条件

- 你有一台阿里云 ECS 服务器（或其他 VPS）
- 服务器有公网 IP

### 第一步：在阿里云 DNS 添加解析

1. **回到阿里云域名管理**
2. **点击 "解析设置"**
3. **添加记录：**
   - 记录类型：A
   - 主机记录：@
   - 记录值：你的服务器公网 IP
   - TTL：10分钟

4. **再添加一条（可选）：**
   - 记录类型：A
   - 主机记录：www
   - 记录值：你的服务器公网 IP

### 第二步：在服务器上配置 Nginx

**SSH 登录到你的服务器，安装 Nginx：**

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install nginx certbot python3-certbot-nginx -y

# CentOS/RHEL
sudo yum install nginx certbot python3-certbot-nginx -y
```

**创建 Nginx 配置文件：**

```bash
sudo nano /etc/nginx/sites-available/agares.online
```

**粘贴以下内容：**

```nginx
server {
    listen 80;
    server_name agares.online www.agares.online;

    location / {
        proxy_pass http://你的电脑IP:38641;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

**启用配置：**

```bash
sudo ln -s /etc/nginx/sites-available/agares.online /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

**配置 HTTPS（重要）：**

```bash
sudo certbot --nginx -d agares.online -d www.agares.online
```

### 第三步：配置内网穿透

因为你的电脑在内网，需要让服务器能访问到它：

**选项 1：使用 frp**

在你的电脑上运行 frp 客户端，连接到服务器。

**选项 2：使用 Cloudflare Tunnel 到服务器**

```bash
# 在服务器上安装 cloudflared
wget https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64
chmod +x cloudflared-linux-amd64
sudo mv cloudflared-linux-amd64 /usr/local/bin/cloudflared

# 建立隧道连接到你的电脑
```

## 💡 推荐方案对比

| 特性 | Cloudflare Tunnel | 阿里云 + 服务器 |
|------|------------------|----------------|

## ❓ 常见问题

### Q: 我没有公网服务器，方案 B 可以用吗？
A: 不可以，方案 B 必须有服务器。建议使用方案 A（Cloudflare Tunnel）。

### Q: 修改 NS 服务器会影响我的网站吗？
A: 不会。只要在 Cloudflare 中正确配置 DNS 记录，一切都会正常工作。

### Q: DNS 生效需要多久？
A: 通常 5-30 分钟，最多 48 小时。

### Q: 我还是想用局域网模式怎么办？
A: 在 Roy 设置中选择"局域网"模式即可，完全免费且无需配置。
