# Roy 优化建议总结

## 🎯 核心问题

你反馈的"卡"和"压缩不对"的根本原因：

1. **压缩触发太晚**：80% 才开始压缩（16万 token），模型已经慢了
2. **保留太多**：12000 tokens 保留量，压完没多久又满了
3. **反复压缩**：3-5 轮就又压缩，用户感觉一直在压缩
4. **配置不对**：用 DeepSeek 模型但没开 DeepSeek 优化模式
5. **反馈不清**：不知道为什么压缩、压了什么、效果如何

## 🚀 立即可执行的优化

### 方案 A：一键优化脚本（最简单）

```bash
cd E:\AIproject\02-roy-harness
node scripts/apply-performance-optimization.js
```

这个脚本会：
- 备份你的当前设置
- 将压缩阈值改为 60%（DeepSeek）或 70%（其他模型）
- 将保留 token 改为 6000（DeekSeek）或 8000（其他模型）
- 关闭动态壁纸（节省性能）
- 自动检测你的模型并应用最佳配置

### 方案 B：手动修改设置文件

编辑 `~/.roy/settings.json`：

```json
{
  // 核心优化：压缩配置
  "compactionThresholdPercent": 60,
  "keepRecentTokens": 6000,
  
  // 核心优化：工作模式（如果用 DeepSeek）
  "workMode": "deepseek",
  
  // 性能优化：关闭不必要功能
  "wallpaper": {
    "dynamic": "none",
    "sceneFps": 0
  },
  
  // 其他设置保持不变...
}
```

### 方案 C：在 Roy 界面中调整

1. 打开 Roy → 设置
2. 找到"性能优化"面板（如果没有，说明需要先更新代码）
3. 点击"根据当前模型自动优化"
4. 保存并重启
