## 2. Roy ↔ Feibo 挂载点

| 层 | Roy 路径 | Feibo 路径 | 对照意图 |
|---|---|---|---|
| Runtime 调度 | `utility/agent-runtime.ts` + orchestrator | `packages__runtime__src__runtime.ts` | 并发上限、排队、账号/工作区隔离 |
| Checkpoint | `file-checkpoints.ts` | `packages__runtime__src__checkpoint.ts` | 写前备份、容量、保留天数、不可撤销理由 |
| Boundary | permission + workspace | `packages__runtime__src__boundary.ts` | 路径 realpath / once 授权（Roy 侧待显式化） |
| Skills | `skill-market.ts` + shared skill-usage | `packages__runtime__src__skills.ts` + `shared/skill.ts` | slug/version/sha 校验（Roy 待补锁） |
| System prompt | `agent-prompt-builder.ts` / slim-mode | `agent-core/agent.ts` → `systemPrompt()` | 按能力开关拼规则 |
| Plan | ExitPlan / planning-* | `agent-core/plan.ts` | 短计划事件协议 |
| Compact | `pi-compaction.ts` + SDK 自动压缩 | `agent-core/compact.ts` | 分层预算 / KEEP_RECENT / 摘要上限 |
| Resume | `buildRecoveryPrompt` + orchestrator resume | `agent-core/resume.ts` | 半完成 tool 步骤重建 |
| Tools/审批 | permission-rules + permission-service | `agent-core/tools.ts` | look-only / risk / approval |
| 并行 | `fast-harness.ts` | `agent-core/parallel.ts` | 工具级并行 vs 任务级并行 |

## 3. 改造时「改哪一层」口诀

- 改**会话策略 / resume 何时触发** → L1 Orchestrator  
- 改**系统提示词文案 / 动态 Context** → L2 Prompt  
- 改**Pi 执行隔离 / 协议** → L3 Runtime（谨慎，协议版本敏感）  
- 改**工具并行、重复调用、瘦身** → L4 FastHarness / Slim  
- 改**安全、备份、路径边界** → L5
