- 人工或脚本：`robocopy` / `Copy-Item` 按清单覆盖 `mirror/*`  
- 每次改造批次结束：更新 `改造进度.md` + 刷新相关 mirror 文件  
- Git：若本目录纳入版本管理，只提交 docs + mirror，忽略任何误拷的 node_modules
