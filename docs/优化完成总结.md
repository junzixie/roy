**实现逻辑：**
```typescript

2. 在预算内尽可能多保留
3. 确保不在 tool 消息处切分
4. 动态回退：检查工具调用完整性
5. 回退到上一个完整轮次
```

### 4. 压缩卡顿诊断与修复

**新增文件：**
- `compaction-performance-diagnostics.ts` - 性能诊断工具

**核心功能：**
- ✅ 卡顿原因分析：截断参数、锚点提取、正则复杂度、整体时间
- ✅ 性能问题分类：truncation / anchors / regex / budget
- ✅ 严重程度评估：low / medium / high / critical
- ✅ 优化建议生成：自动推荐配置调整
- ✅ 实时性能监控：CompactionPerformanceMonitor

**诊断规则：**
```typescript
- truncateChars < 1000 → 高严重性：频繁触发锚点提取
- truncateChars > 10000 → 中严重性：压缩效果不明显
- averageReasoningLength > 5000 → 高严重性：锚点提取耗时
- compactionTimeMs > 2000 → 严重卡顿
- compactionTimeMs > 1000 → 明显延迟
```

**实时监控：**
- 记录最近 10 次压缩时间
- 检测性能下降趋势
- 自动生成优化建议

### 5. 磁盘管理增强

**新增文件：**
- `disk-cleanup-enhanced.ts` - 磁盘清理增强功能

**核心功能：**
- ✅ 归档项目识别：超过 30 天未访问
- ✅ 残余文件类型分析：统计文件类型分布
- ✅ 最后访问时间跟踪
- ✅ 智能清理优先级（1-5 级）
- ✅ 清理建议生成

**优先级计算规则：**
```typescript
基础分 1 分，然后：
- 归档 > 90 天 → +2 分
- 归档 > 60 天 → +1 分
- 占用 > 5GB → +2 分
- 占用 > 1GB → +1 分
- 会话数 ≤ 2 → +1 分（可能是测试项目）
- 有残余文件 → +1 分
最高 5 分
```

**文件类型分类：**
- 可安全删除：.log / .tmp / .cache / .bak / .DS_Store
- 需要确认：.md / .txt / .json / .js / .ts / .py

**增强的 StorageCategory：**
```typescript

}
```

**增强的 StorageProjectUsage：**
