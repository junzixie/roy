# P1 设计与落地说明（对照 Feibo）

> 更新：2026-10-22  
> Cloud Codex：待补

## 总原则

小步、可回滚；不确定只写设计；不破坏现有 Pi runtime 协议。

## 1. Compact 预算

| 项 | 说明 |
|---|---|
| Feibo | `compact.ts`：TOKEN_BUDGET、KEEP_RECENT、SHORT_TOOL_OUTPUT、SUMMARY_* |
| Roy 现状 | `pi-compaction.ts` 只管自动压缩阈值阈值；slim-mode 另做 prompt 瘦身 |
| 本轮落地 | 在 `pi-compaction.ts` **追加导出分层预算常量**（不改阈值计算行为）+ 测试断言常量存在 |
| 未接线 | 真正按 Feibo 做消息级 drop/摘要需改 Pi adapter 消息管线 → 列为下一步 |

## 2. Resume 半完成步骤

| 项 | 说明 |
|---|---|
| Feibo | `resume.ts`：finishedSteps / brokenSteps / resumeNote |
| Roy 现状 | SDK resume + `buildRecoveryPrompt`（会话级恢复说明） |
| 本轮落地 | 新增 `agent-resume-steps.ts`（纯函数 + 单测）；`buildRecoveryPrompt` **可选**附加半完成步骤摘要（从 SDK 消息启发式提取，失败则静默跳过） |
| 风险 | 启发式不完全等于 Feibo 事件流；默认不影响 resume 成功路径 |

## 3. Checkpoint 容量 / 边界

| 项 | 说明 |
|---|---|
| Feibo | MAX_FILE 50MB、MAX_TOTAL 500MB、MAX_PATHS、KEEP_DAYS 7、symlink 不可撤 |
| Roy 现状 | MAX_FILE 10MB、KEEP_DAYS 14；无总容量；无 skipReason |
| 本轮落地 | 增加 `MAX_TOTAL_BYTES`、`MAX_PATHS`、导出策略常量、`skipReason`；超限跳过备份；symlink 跳过；扩展测试 |
| 行为变化 | 仅「原本会备份、现因总容量/路径数/符号链接跳过」→ 更保守，不改变恢复 API |

## 4. Skill sha 锁

| 项 | 说明 |
|---|---|
| Feibo | slug/version/sha256 校验 + libs lock |
| Roy 现状 | skill-market 只扫 frontmatter，无完整性哈希 |
| 本轮落地 | 新增 `@roy/shared` 工具 `skill-integrity.ts`（SAFE_SLUG、规范化、sha256 文本/可选文件）；**不强制拦截安装** |
| 下一步 | market/安装路径调用 verify，失败只告警 |

## 5. 只读命令启发式

| 项 | 说明 |
|---|---|
| Feibo | LOOK_ONLY + pipeline 过滤器 |
| Roy 现状 | SAFE_BASH_PATTERNS + hasDangerousStructure + isDangerousCommand |
| 本轮落地 | 扩展 Windows/诊断只读模式；新增 `isLookOnlyBashCommand`；`isSafeBashCommand` 复用；单测 |
| 注意 | 不放宽危险结构检测（管道/重定向仍拒绝自动放行） |
